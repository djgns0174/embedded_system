# [학교] 임베디드 시스템 프로젝트

# 자율주행 미니카

1. 카메라에서 얻은 영상데이터를 보고 차선을 감지를 한다.
    - 차선감지
    - 픽셀단위로 차선인지 아닌지 0과 1로 분류
2. 감지된 차선에 따라서 바퀴의 방향을 제어한다. 또한 차선 중심과 차량의 위치에 따라서 차량을 제어한다.
3. 테스트를 진행한다.

## 차선감지

### u-net : 픽셀을 개별적으로 예측할 수 있기 때문에 차선감지에 적합한 모델임.

## 현재까지의 진행상황

1. 데이터셋 준비
    - 데이터를 256 x 256 으로 resize
    - 라벨링 데이터(json)을 mask.png로 변환(차선:흰색, 나머지:검정색)
2. 모델 학습
    - resize_data, mask_data를 각각 학습 시킴
    - 현재는 epoch 10으로 , 데이터 1개로 학습시킴.
    - 그래서 epoch 50으로 늘렸더니 loss가 감소하지 않음.
3. 모델 검증
    - 현재까지 학습데이터로 검증을 하였으나 예측 안됨.
